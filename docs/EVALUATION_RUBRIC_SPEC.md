# Research Factory Evaluation Rubric Specification

## Academic Standards Compliance
- **Authority Score (30%)**: Verified domain TLD (.edu, .gov, .org) and citation count.
- **Temporal Freshness (25%)**: Recency weighting for rapidly evolving domains.
- **Methodological Rigor (25%)**: Statistical significance and empirical evidence.
- **Consensus Alignment (20%)**: Cross-verification across multiple disjoint sources.
